Installation
============

Install from PyPI
-----------------

.. code-block:: bash

   pip install smith-utils

The package installs the ``smith`` command for CLI access to selected utilities.

Install from source
-------------------

.. code-block:: bash

   git clone https://github.com/yeiichi/smith-utils
   cd smith-utils
   pip install .

Verify the CLI installation:

.. code-block:: bash

   smith --help

Requirements
------------

- Python 3.10+
