Installation
============

Install from PyPI
-----------------

.. code-block:: bash

   pip install smith-utils

The package installs ``smith`` for general utilities and ``com-name-cleaner``
for Japanese organization names.

Install from source
-------------------

.. code-block:: bash

   git clone https://github.com/yeiichi/smith-utils
   cd smith-utils
   pip install .

Verify the CLI installation:

.. code-block:: bash

   smith --help
   com-name-cleaner --help

Requirements
------------

- Python 3.10+
